Testscenario's

Hiermee boots je gebeurtenissen na voor het monitoringteam. Alles gebeurt alleen binnen deze lokale testomgeving.

Applicatiefout

Laat de applicatie een exception gooien. In het log verschijnt ERROR Test exception generated.

Veel API-verkeer

Stuurt een reeks verzoeken naar GET /api/stations.

Hoge belasting

Maakt in één keer veel sensorrecords aan. Dat zorgt voor database-activiteit, CPU-gebruik en extra logging.

Mislukte logins en containeruitval

Log uit en probeer een paar keer een verkeerd wachtwoord, of gebruik scripts/scenario2-foute-logins.sh.

Containeruitval: docker stop webapp (of docker stop database), daarna weer docker start ….
